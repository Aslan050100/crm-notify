# crm-notify

Сервис InsightIT для автоматических WhatsApp-сообщений клиентам по событиям в CRM.
Каждый день в заданное время находит в CRM людей по условию сценария, отправляет
сообщение через **Wazzup** и ставит в карточке отметку, чтобы не отправить повторно.

| | Сейчас | Дальше |
|---|---|---|
| CRM | amoCRM | Битрикс24 (черновой коннектор уже есть) |
| Канал | Wazzup (WhatsApp) | — |
| Сценарии | 🎂 день рождения | профосмотр через 6 мес., «давно не были», … |

Первый клиент — клиника **MyDent** (`clients/mydent.yaml`).

---

## Установка на Windows (один раз)

1. Установите **Python 3.11+** с [python.org](https://www.python.org/downloads/).
   В установщике обязательно отметьте **«Add python.exe to PATH»**.
2. Скачайте проект: на GitHub → зелёная кнопка **Code → Download ZIP**,
   распакуйте, например, в `C:\crm-notify`.
3. Дважды щёлкните **`install.bat`**. Он создаст окружение, поставит зависимости
   и файл **`.env`**.
4. Откройте `.env` в Блокноте и впишите:
   - `MYDENT_AMO_TOKEN` — долгосрочный токен amoCRM
     (Настройки → Интеграции → ваша внешняя интеграция → «Ключи и доступы»);
   - `MYDENT_WAZZUP_API_KEY` — ключ API Wazzup.
   Оставьте `MODE=test`.
5. Дважды щёлкните **`check.bat`** — должно быть три зелёные галочки:
   доступ к amoCRM, канал 7747 в Wazzup, и список, у кого сегодня день рождения
   с примером текста.
6. Правой кнопкой по **`install_task.ps1`** → **«Выполнить с помощью PowerShell»** —
   задача появится в Планировщике Windows: каждый день в 11:00 (и каждый час до 20:00,
   если компьютер включили позже; повторных отправок не будет).

## Тестовый режим → боевой

- `MODE=test` — ничего не отправляется. Каждый день в `data\reports\` появляется файл
  `ГГГГ-ММ-ДД_mydent_birthday_test.csv`: кого бы поздравили и каким текстом.
- Проверьте отчёты 2–3 дня. Если всё верно — поменяйте в `.env` на `MODE=live`.

## Полезное

| Файл | Что делает |
|---|---|
| `check.bat` | проверка доступов + кто сегодня именинник (ничего не отправляет) |
| `run_now.bat` | выполнить прямо сейчас (в режиме из `.env`). Можно за другую дату: `run_now.bat --date 2026-11-05` |
| `due.bat` | то, что запускает планировщик |
| `data\crm_notify.log` | журнал работы |
| `data\reports\` | отчёты по каждому запуску (CSV, открывается в Excel) |

Команды напрямую: `.venv\Scripts\python -m crm_notify {check|setup|run|due|serve|log}`.

## Как работает сценарий «День рождения»

1. Читает все контакты amoCRM с полем «День Рождения».
2. Отбирает тех, у кого день и месяц = сегодня (родившихся 29.02 поздравляет 28.02 в невисокосный год).
3. Пропускает: «Запрет автоматических сообщений», без телефона, уже поздравленных в этом году
   (поле «Поздравлен с ДР (год)» + собственный журнал), дубли одного номера.
4. Обращение по имени — только если в поле «Имя» действительно имя (не цифры и не «Клиент»).
5. Отправляет через Wazzup с паузой 15–45 с между сообщениями, ставит отметку года
   и примечание в карточке.

Текст, время и лимиты — в `clients/mydent.yaml`.

## Новый клиент

Скопируйте `clients/mydent.yaml` в `clients/<id>.yaml`, поправьте поля и текст,
добавьте его переменные в `.env`. Код менять не нужно.

## Безопасность

Токены и ключи — только в `.env` (он в `.gitignore`). Не отправляйте их в чаты и не коммитьте.
